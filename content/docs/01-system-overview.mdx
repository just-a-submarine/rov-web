## 任務定義

這段說明本 ROV 設計的核心任務邊界——在這個限制內，所有硬體選型與系統設計都必須達標。

- **通訊距離**：最遠約 200 公尺
- **深度**：20 cm ～ 1 公尺

---

## 材料清單

以下清單涵蓋整台 ROV 及地面站所需的全部零組件，依功能分為七大類。每類開頭有簡短說明，幫助快速掌握各類零件的角色。

### 主控與電子

本類為 ROV 的「神經系統」——負責感測、運算、通訊與輸出控制。兩端（ROV 與地面站）共用同款主控晶片，簡化韌體維護。

| 項目 | 規格 |
| ---------- | ---------------------------------------------------------- |
| ROV 主控 | ESP32-S3-CAM（N16R8） |
| 地面站主控 | ESP32-S3-CAM（N16R8） |
| GPS | Neo-M8N（模組體艙內，主動式天線 LNA 28dB 至浮標） |
| 電子羅盤 | QMC5883P（I²C 0x2C） |
| 水壓感測器 | MS5837-02BA（I²C 0x76） |
| 電流計 | INA260（I²C 0x40） |
| IO 擴展板 | MCP23017（I²C 0x20） |
| 馬達驅動板 | BTS7960 × 3 |
| MicroSD 卡 | 32GB |
| 繼電器模組 | 單路 12V，設為**高電位觸發** |
| 升壓模組 | 5V/2A × 2（ROV 系統電路與地面站系統各 × 1） |

### 補光

水下環境能見度低，兩顆白光 LED 提供前視補光。

| 項目 | 規格 |
| -------- | ------------- |
| LED × 2 | 4W，12V，白光 |

### 推進系統

三顆防水有刷馬達提供 X、Y、Z 三軸推力，搭配各自的 BTS7960 驅動板獨立控制。

| 項目 | 規格 |
| --------- | ------------------------------------------------------------ |
| 馬達 × 3 | 12V 3A 防水有刷，直徑 30mm，本體 60mm，含軸 78mm（附螺旋槳） |

### 電力系統

動力與系統電路分電，避免大電流馬達突波影響控制器穩定性。

| 項目 | 規格 |
| ---------- | ---------------------------------- |
| 動力電池 | 3S4P，12V 13.6Ah，XT60（含保護板） |
| 系統電池 | 18650 × 1 顆，3400mAh |
| 地面站電池 | 18650 × 1 顆，3400mAh |
| 動力配線 | 12AWG 矽膠線 |
| 系統配線 | 16AWG 電線 |

### 艇體結構

艇體採三段式設計，中段由 3D 列印製作，前後端蓋選用現成 PP 端蓋配合密封工序組合而成。

| 項目 | 規格 |
| ------------ | --------------------------------- |
| 主體（中段） | PETG 列印（Bambu Lab A1） |
| 前蓋 / 後蓋 | PP 端蓋（現成品）× 2 |
| 鏡頭視窗 | PS 透明半球 |
| 水平尾翼 | PETG 列印 × 2 |
| 重力平衡塊 | 適量（置於艙底調整重心與防側翻，待實測重量與排水量後決定） |
| PETG 線材 | 1 kg |

### 密封材料

不同接合面採用不同密封策略：PP 端蓋需專用底料活化，穿孔則以環氧樹脂灌封，確保所有進出線纜位置水密。

| 項目 | 用途 |
| ------------------ | -------------------------------------------------- |
| PP 專用底料 | 接縫 A/B PP 面活化 |
| 雙劑型 PP 專用膠 | 接縫 A/B 第一道黏合 |
| 自融膠帶 | 接縫 A/B 主防水層 |
| PVC 絕緣膠帶 | 接縫 A/B 防磨損保護 |
| 低黏度雙液環氧樹脂 | 接縫 C、穿孔灌封、馬達穿線孔灌封、MS5837 灌封、PETG 外皮 |
| 熱熔膠 | 穿孔灌封輔助堵底 |
| 熱縮管 | MS5837 電氣隔離 |

### 天線與通訊線纜

ROV 潛水時，天線透過延長線引至水面浮標，維持 Wi-Fi 通訊品質。

| 項目 | 規格 |
| ---------------- | -------------------------------------------- |
| ESP32 Wi-Fi 天線 | IPEX→SMA + 3m SMA 延長線（RG316 或 LMR100） |
| GPS 天線 | 主動式（LNA 28dB），3m 延長線 |
| 浮標外殼 | PET 防水盒 + 泡棉 |
