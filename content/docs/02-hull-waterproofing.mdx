## 艇體結構

這段說明 ROV 的機械結構設計——三段式拼裝、感測器/馬達的安裝位置，以及所有穿孔的位置與密封方式。理解結構是進行防水工序前的必要基礎。

### 三段式設計

艇體分為前端、中段、後端，前後端蓋選用現成 PP 端蓋，中段由 PETG 3D 列印製作，所有電子元件均安裝於中段。

| 段落 | 材質 | 說明 |
| ---- | ------------------------- | ------------------------------ |
| 前端 | PP 端蓋（現成品） | 純封閉端蓋，無任何開孔或安裝物 |
| 中段 | PETG 列印（Bambu Lab A1） | 艇體主體，所有內容物均安裝於此 |
| 後端 | PP 端蓋（現成品） | 純封閉端蓋，無任何開孔或安裝物 |

### 結構細節

- **PS 半球觀察窗**：嵌入 PETG 中段頂部開孔，OV5640 置於半球後方取像
- **尾翼**：直接裝於 PETG 中段
- **重心**：電池置艙底，搭配配重塊微調，維持微正浮力
- **馬達電線**：水平馬達線由機翼延伸臂根部穿線孔（D=6mm，沿 X 軸徑向穿入艙內）進入艙室；垂直馬達線由馬達座底部引線孔（D=6mm）進入艙室；各穿線孔以環氧樹脂灌封防水
- **垂直馬達**：置於船底圓柱形馬達座（OD=38mm，高 33mm），馬達線從底部引線孔（D=6mm）進入艙室

### 外殼開孔（共 2 個）

開孔是水密設計的最高風險點，每個孔的密封方式均不同，需嚴格按工序執行。

| 孔號 | 用途 | 位置 | 密封方式 |
| ------ | -------------------------------------------------------------------------- | ------------- | -------------------------- |
| 頂部孔 | PS 半球嵌入（OV5640 觀察窗） | PETG 中段頂部 | 接縫 C（環氧樹脂黏合收邊） |
| 孔 1 | MS5837 訊號線 + GPS 天線線（主動式）+ ESP32 天線（IPEX→SMA，3m SMA 線） | PETG 中段側面 | 熱熔膠堵底 + 環氧樹脂灌封 |

## 防水方案

本段是整個製作流程中最關鍵的環節。ROV 共有三類接縫（A/B/C）與四個穿孔，每一處的材質組合不同，需分別按工序操作。任何遺漏都可能導致浸水損壞。

### 接縫與密封點總覽

| 編號 | 位置 | 接合材質 |
| ---------- | ------------------------------------------- | ----------------- |
| 接縫 A | 前端 PP 蓋 ↔ PETG 中段 | PP ↔ PETG |
| 接縫 B | 後端 PP 蓋 ↔ PETG 中段 | PP ↔ PETG |
| 接縫 C | PS 半球 ↔ PETG 中段頂部 | PS ↔ PETG |
| 穿孔 1 | MS5837 訊號線 + GPS 天線線 + ESP32 SMA 線 | PETG 孔壁 |
| 馬達穿線孔 | 馬達動力線（每顆馬達 2 條，共 6 條） | 機翼臂根部 D=6mm × 2 + 垂直馬達座引線孔 D=6mm × 1 |

### 接縫 A / B 密封工序（PP ↔ PETG）

PP 與 PETG 化學性質差異大，普通膠無法黏合。必須先以專用底料活化 PP 面，再依序疊加膠合、自融膠帶與環氧樹脂，形成多道防線。

1. **表面處理**：接縫兩側以砂紙打磨，去除油脂；PP 面塗佈 PP 專用底料，靜置活化
2. **專用膠黏合**：塗佈雙劑型 PP 專用膠（雙液混合），貼合夾緊，完全固化
3. **自融膠帶（主防水層）**：拉伸 1.5 ～ 2 倍纏繞，重疊率 50%，纏繞兩層
4. **PVC 絕緣膠帶（防磨損）**：自融膠帶外側纏一層，純防磨損
5. **環氧樹脂塗佈**：外露 PETG 外皮整體薄塗多次，填補列印層間孔隙

### 接縫 C 密封工序（PS ↔ PETG）

PS 半球為光學透明件，主要靠環氧樹脂結合。

1. 打磨兩側（PS 半球法蘭面與 PETG 孔緣）
2. 塗佈低黏度雙液環氧樹脂，貼合固定，完全固化
3. 外圈補一層環氧樹脂收邊

### 穿孔 1 灌封工序

三條線纜共用一個側孔穿入艙室，灌封時需分次少量，確保環氧樹脂完整填滿線纜間隙。

1. 三條線纜穿過孔洞，調整至最終位置
2. 艙內側打入熱熔膠堵底
3. 艙外側灌入低黏度雙液環氧樹脂，分次少量，填滿間隙
4. 靜置完全固化（建議 24h 慢固化型）
5. 外緣補一層環氧樹脂收邊

### 馬達穿線孔灌封工序

馬達動力線由機翼延伸臂根部穿線孔（D=6mm）進入艙內（左右水平馬達各 1 個），垂直馬達線由馬達座底部引線孔（D=6mm）進入艙內，共 3 個穿線孔。

1. 馬達電線穿入引線孔，調整至最終位置
2. 孔外側灌入低黏度環氧樹脂，分次少量填滿間隙
3. 孔內側艙室面同樣補封
4. 靜置完全固化（建議 24h 慢固化型）

### MS5837 艙外密封工序

MS5837 水壓感測器的密封方式特殊——感測孔本身受凝膠保護，**不可被任何材料堵塞**，只能封裝 PCB 背面與焊點。

<Callout type="danger" title="感測孔禁止封堵">
感測孔內有凝膠保護膜，感測孔須完全暢通，不得塗佈任何材料。只封裝 PCB 背面與線材焊點。
</Callout>

- PCB 背面與線材焊點整體灌低黏度環氧樹脂，僅保留感測孔面暴露
- PCB 背面與艇體金屬件之間墊熱縮管，防電偶腐蝕
- 感測孔朝向：朝下或側面，避免正對水流

### 防水驗證流程

密封工序完成後需經過三道驗證，由輕到重逐步升級，確認每個接縫與穿孔都達到水密標準後再進行實際入水測試。

<Callout type="warning" title="氣壓測試標準">
充入 0.3 bar 後需靜置 15 分鐘無洩壓，且以肥皂水檢查所有接縫與穿線孔均無起泡，方視為通過。
</Callout>

| 步驟 | 方法 |
| -------- | ---------------------------------------------------------------- |
| 氣壓測試 | 充入 0.3 bar，肥皂水檢查所有接縫與穿線孔，靜置 15 分鐘無洩壓 |
| 淺水浸泡 | 水桶靜置 30 分鐘，開蓋確認內部無水氣 |
| 深度測試 | 實際潛水至最大工作深度，回收後開蓋確認 |

## 浮力與重量說明

本段說明艇體排水量的理論估算，以及正式入水前需完成的實測流程。

本專案艇體設計之理論排水體積約為 **1590 cm³**（在純水中約提供 **1590 g 浮力**）。為了確保浮力與重量數據的絕對精準，我們將在**實體硬體與結構裝配完成後，進行實際秤重與排水量測試**。

- **實測重量與配重設計**：待實際秤重取得精確數值後，將在此補回具體元件重量與浮力分配表。
- **中性浮力調整**：屆時將根據實際負浮力大小，在艙外加裝少量微型高密度閉孔防水泡棉以達到「微正浮力」，確保在緊急停車或電力中斷時，潛艇能自動且緩慢地上浮至水面。
