## 一、外殼尺寸規格

### 整體尺寸

| 項目 | 數值 | 說明 |
|------|------|------|

### PP 端蓋來源

PP 端蓋取自市售圓柱形 PP 保鮮盒底部切開取蓋（錐形容器，越靠近開口外徑越大）：

| 位置 | OD | 壁厚 |
|------|-----|------|
| 窄端（底部） | ≈ 86.7 mm | 0.85 mm |
| **寬端（本設計採用）** | **≈ 90 mm** | 0.85 mm |

建議精確量測切割高度處的實際 OD，依實測值微調插槽尺寸。

### 座標系

- **Z 軸**：艇體長軸（Z=0 後端 / Z=250 前端）
- **Y 軸**：垂直方向（Y+ 為艇頂）
- **X 軸**：水平橫向（X+ 為右舷）
- **原點**：艇體後端面中心

```
後端(Z=0)  ←────────── 250 mm ──────────→  前端(Z=250)
    ┌──────────────────────────────────────────┐
    │←10mm→      主艙有效艙室      ←10mm→ │
    │PP 插槽  （有效長 230 mm）  PP 插槽   │
    └──────────────────────────────────────────┘
                  OD = 90 mm，壁厚 1.5 mm
```

## 三、Bambu Studio 切片參數

### Quality（品質）

| 參數 | 建議值 | 說明 |
|------|--------|------|
| Layer height | **0.16 mm** | 層高越薄，層間融合越好，防水性提升 |
| Initial layer height | 0.20 mm | 第一層稍厚有助附著 |
| Outer wall 線寬 | **0.45 mm** | 略加寬填滿層間微縫 |
| Inner wall 線寬 | **0.46 mm** | 同理 |
| Smart scarf seam | ✅ 開啟 | 避免 Z seam 留縫，對防水關鍵 |

### Strength（強度）

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **Wall loops** | **4** | 最關鍵：1.5mm ÷ 0.45mm ≈ 3.3 條，設 4 讓 1.5mm 壁厚自動達到 100% 壓實，徹底消除層間縫隙 |
| **Detect thin wall** | **✅ 開啟** | 必開！壁厚 1.5mm 屬薄壁，不開會出現未填充縫隙 |
| Top shell layers | **7** | 頂面密實（配合 0.16mm 層高） |
| Bottom shell layers | **5** | 底面加厚 |
| **Sparse infill density** | **15% ～ 20%** | 全局 infill；防水外殼透過 Wall Loops 自動達到 100% 實心，不需 100% 全局填充 |
| Sparse infill pattern | **Gyroid** | 兼顧結構剛性、高排水性與減輕實體乾重 |
| Infill/Wall overlap | **25%** | 消除壁-填充接縫微縫 |

### 💡 關鍵：分區填充與輕量化設計

為了在 **1590g 理論浮力限制**下，防止 3D 列印外殼過重（若整機 100% 實心填充，實重將高達 300g 以上，導致嚴重的負浮力），本專案採用**「壁厚-填充分離」**與**「分區填充」**的優雅策略：

1. **防水薄壁外殼（壁厚 1.5mm）**：
   當切片設定 `Wall loops` 設為 **4** 時，由於噴嘴外圈線寬為 0.45mm，4 層壁圈（4 × 0.45mm = 1.8mm）的總寬度已完全超越了 1.5mm 的實體壁厚。
   這意味著在切片時，**1.5mm 的防水圓柱外殼會被 100% 自動壓實為全實心**，完全沒有任何內部 infill 的空隙，從而達到物理上的絕對防水。
2. **艙外非防水結構（如水平馬達座、垂直馬達座、水平尾翼）**：
   這些結構屬於較厚實的實體，若採用 100% 填充，會產生多餘的重量。
   - **做法**：在 Bambu Studio 中，將全局 `Sparse infill density` 設為 **15% ~ 20%**，並採用 **Gyroid**（迴轉體）填充圖樣。
   - **優勢**：Gyroid 圖樣具備三維開放孔洞結構，水流可以自由進出這些非防水腔體。當潛艇浮出水面時，內部的積水能迅速排乾；而水下航行時，艙外結構內的水流與外界壓力平衡，既不需要承受抗壓載荷，又可將外殼乾重控制在 **150g 以內**，確保潛艇能保有微正浮力（電力中斷自動上浮）。

## 四、防水與輕量化優化順序

1. **Wall loops 設為 4 以上 + Detect thin wall 開啟** — 消除 1.5mm 壁內空隙，自動達成外殼實心防水（最關鍵）
2. **非防水艙外結構採用 15%~20% Gyroid 填充** — 消除多餘內部質量，實現排水輕量化，控制乾重於 150g 以內
3. **噴嘴溫度 240–245°C + 風扇降至 30–50%** — 提升層間黏合力
4. **Layer height 0.2→0.16mm** — 增加層間密封面積
5. **外壁速度 200→80 mm/s** — 讓塑料充分融合
6. **Infill/Wall overlap 15%→25%** — 消除壁-填充接縫
